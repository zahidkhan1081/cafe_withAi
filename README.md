# Cafe Management and Online Ordering

A production-oriented cafe management and online ordering application.

## Planned Stack

- Frontend: React
- Backend: Node.js with Express
- Database: PostgreSQL
- API: REST
- Version control: Git and GitHub

## Repository Structure

- `frontend/` - Web client application. React setup will be added in a later checkpoint.
- `backend/` - Server application and REST API. Express setup will be added in a later checkpoint.

## Development Checkpoints

This repository is being built incrementally. The current checkpoint establishes only the repository foundation; application code, dependencies, database schema, and infrastructure will be introduced in later checkpoints.
